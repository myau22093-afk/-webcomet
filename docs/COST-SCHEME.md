# Деньги и честность WebComet

## Схема запроса

```
Запрос
  │
  ├─ «привет / помоги» ──────────────► Чат (DeepSeek, дёшево) — не сайт
  │
  ├─ Есть ТОЧНЫЙ такой же промпт в кеше?
  │     ДА ─► −80 ток. · API 0 ₽ · жирный плюс · клиенту дешевле полной генерации
  │     НЕТ ─┐
  │          │
  ├─ Правка («убери», «красным») ───► Terra −55 · плюс
  ├─ Ниша (стоматология…) ──────────► шаблон + Terra −55 · плюс
  ├─ Создать / экспресс / скрин ────► Fable −250 · небольшой плюс (~API 130 ₽)
  └─ Иначе ─────────────────────────► модель из селекта · по её цене
```

## Маржа (ориентир при ~1 ₽/токен)

| Случай | Клиент | API | Ты |
|--------|--------|-----|----|
| Кеш | 80 ≈ 80 ₽ | 0 | жирный плюс |
| Правка / ниша | 55 ≈ 55 ₽ | низкий | плюс |
| Новый Fable | 250 ≈ 250 ₽ | ~130 ₽ | небольшой плюс |
| Чат DeepSeek | 2 | копейки | плюс |
| Картинка Flash | 70 | умеренно | небольшой плюс |

## Честность

- Перед генерацией UI показывает, сколько спишем и какую модель.
- После — `modelReason` (почему эта модель / кеш).
- Нет тихой подмены Claude → DeepSeek.
- Кеш платный (80), но дешевле полного Fable (250).
