WebComet - деплой проекта (не лендинг!)
========================================

Этот репозиторий содержит WebComet (генератор сайтов на Next.js).

Быстрый деплой на уже поднятый VPS (Docker)
-------------------------------------------
На сервере (SSH):

  cd /opt/webcomet
  bash scripts/deploy-vps.sh

или вручную:

  cd /opt/webcomet
  git pull origin main
  docker compose up -d --build
  curl -I http://127.0.0.1/

После деплоя в Cloudflare — cache rule для /_next/static (см. cloudflare-cache.md).
Масштаб 3–9к онлайн — см. SCALE.md и docker-compose.scale.yml.

Цены токенов: lib/tokenConfig.ts (Basic 500₽ / Pro 1800₽ / Business 4000₽ / Enterprise 14000₽).

Важно: NEXT_PUBLIC_* ключи зашиваются при docker build — после правки .env нужен --build.
