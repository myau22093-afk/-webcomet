WebComet — деплой проекта (не лендинг!)
========================================

Это архив ПРИЛОЖЕНИЯ WebComet (генератор сайтов на Next.js).
Это НЕ статический сайт из «Скачать ZIP» в дашборде.

ВАЖНО про Рег.ру
----------------
Обычный виртуальный хостинг (public_html, PHP) НЕ запустит WebComet.
Нужен VPS / Cloud с Node.js 20+ (у Рег.ру: VPS, Cloud VPS и т.п.).

Либо проще для теста:
- Vercel (vercel.com) — бесплатно, заточен под Next.js
- Railway / Render / Timeweb Apps

Быстрый старт на VPS
--------------------
1. Распакуйте архив на сервер (например в /var/www/webcomet).
2. Установите Node.js 20 LTS.
3. Скопируйте .env.example → .env.local и заполните ключи
   (Supabase, Promptra/ProxyAPI, URL сайта).
4. В Supabase выполните SQL из папки supabase/ (миграции).
5. Команды:

   npm install
   npm run build
   npm start

   # или через PM2:
   npm install -g pm2
   pm2 start npm --name webcomet -- start
   pm2 save

6. В .env.local поставьте:
   NEXT_PUBLIC_APP_URL=https://ваш-домен.ru

7. Перед nginx/apache проксируйте порт 3000 на 80/443.

Что НЕ входит в архив (намеренно)
---------------------------------
- node_modules (ставьте на сервере: npm install)
- .next (соберётся: npm run build)
- .env.local (секреты — заполните сами из .env.example)

Файлы загрузок пользователей
----------------------------
Папка public/uploads должна быть доступна на запись.
